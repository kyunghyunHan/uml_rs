# UML Studio 사용 가이드

## 설치와 시작

개발 빌드는 Rust 1.88 이상과 macOS Xcode Command Line Tools가 필요하다. 이번 실제 검증은 Rust 1.99/macOS Apple Silicon에서 수행했다.

```sh
cargo run --locked
bash scripts/package-macos.sh
```

로컬 결과 `dist/UML Studio.app`을 원하는 폴더에 복사해 실행한다. ZIP은 `dist/UML-Studio-0.1.0-macos-arm64.zip`이다. 현재 패키지는 ad-hoc 서명이며 Developer ID 서명/Apple 공증을 받지 않았다. 인터넷 다운로드본의 Gatekeeper 설치 경험은 검증 전이다. 출처/서명을 확인하지 않고 시스템 보안을 전역 해제하지 않는다. 공개 배포는 release-checklist의 미완료 항목을 먼저 해결해야 한다.

시작 화면에서 새 프로젝트·프로젝트 열기·정렬 예제를 선택한다. `examples/review.umlproj`는 긴 한글·패키지·중첩 활성·프래그먼트·생성/소멸을 포함한다. Linux/Windows 실행 방법은 README 및 CI를 참고하되 이번 로컬 작업에서 실제 실행하지 않았다.

## 편집

상단 파일/저장/실행 취소/다시 실행/내보내기, 왼쪽 프로젝트·요소 목록, 중앙 탭/캔버스, 오른쪽 Inspector를 사용한다. 작은 창에서 양쪽 패널은 자동 접히며 보기 메뉴로 다시 연다. 보기 → 다크 테마를 선택하면 다음 실행에도 유지된다. 다이어그램 종이는 흰색이며 내보내기 색상은 테마와 독립이다.

1. 요소 추가에서 종류를 고르고 캔버스를 클릭한다. 선택 후 Inspector로 이름·명세·멤버를 편집한다.
2. 관계 연결에서 종류를 고르고 시작 → 도착 순서로 클릭하거나 드래그한다. 유효하지 않은 대상은 이유가 표시되며 시작점은 유지된다. Esc로 취소한다.
3. 일반화의 도착은 상위 타입, 구현의 도착은 인터페이스, 집합/합성의 시작은 전체다. include는 포함 대상, extend는 기본 유스케이스로 향한다. 탐색 상태는 양 끝에서 설정한다.
4. 경로 자동은 직선을 우선하고 장애물을 우회한다. 직선은 장애물 우회를 생략하고, 직교는 수평/수직 선분을 쓴다. 수동 점은 모드 변경으로 지우지 않는다. 초기화하려면 자동 경로 초기화를 사용한다.
5. 패키지/경계 소속은 Inspector의 ID 연결이다. 경계를 움직이면 모든 명시적 하위 요소가 함께 움직인다. 경계 삭제는 자식을 남기고 소속을 해제한다.
6. 시퀀스 참여자·메시지·활성·alt/opt/loop는 추가 메뉴와 Inspector로 만든다. 이벤트/참여자 순서는 왼쪽 목록 드래그로 바꾸며 참조는 ID로 유지된다.

클릭 선택, Shift/Cmd/Ctrl+클릭 다중 선택, Alt+클릭 겹친 요소 순환, 빈 공간 드래그 범위 선택. Space+드래그 또는 가운데/오른쪽 드래그로 이동, Cmd/Ctrl+휠·핀치로 포인터 기준 확대. F는 화면 맞춤이다. 텍스트 편집 중에는 캔버스 단축키를 가로채지 않는다.

| 키 | 기능 |
|---|---|
| Cmd/Ctrl+N, O | 새 프로젝트, 열기 |
| Cmd/Ctrl+S, Shift+Cmd/Ctrl+S | 저장, 다른 이름 저장 |
| Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z | Undo, Redo |
| Cmd/Ctrl+A, C, V, D | 전체 선택, 내부 복사, 붙여넣기, 복제 |
| Delete/Backspace | 선택 삭제 |

Undo/Redo는 최대 100개 스냅샷이다. 연속 입력/한 번의 드래그를 묶고 화면 이동/확대는 이력에 넣지 않는다. 클립보드는 앱 내부용이다. 지원 범위와 추가 사용법은 루트 README에 있다.

## 안전한 저장과 복구

`.umlproj`는 UTF-8 JSON v3다. v1/v2를 열면 메모리에서 마이그레이션하며 저장 전 원본은 그대로다. 깨진 JSON·중복 ID·구조 오류·32MiB 초과 파일은 열기를 거부한다. 의미 오류는 하단 진단에서 원인을 클릭해 수정한다. 정상 저장은 진단을 통과해야 하지만 자동 복구는 구조가 유효한 수정 내용을 보존한다.

`•` 및 하단 변경 상태를 확인한다. 창 닫기/다른 프로젝트로 교체할 때 저장·버리기·취소를 선택한다. 자동 복구는 약 20초마다 이루어지므로 그 사이 변경은 강제 종료 시 사라질 수 있다. 정상 저장과 별개다.

- 데이터 위치: 기존 호환성을 위해 `$HOME/.uml-studio`. `UML_STUDIO_HOME`으로 변경할 수 있다. HOME이 없으면 임시 폴더의 `uml-studio` 아래를 사용한다. 권한/용량 오류는 저장 대화상자 또는 상태줄에 표시한다.
- `recent.json`: 최근 파일과 테마. `recovery-<UUID>.umlproj`: 세션별 복구 사본. 기존 `recovery.umlproj`도 읽는다.
- 시작 화면의 복구 목록에서 복구하면 새 미저장 프로젝트로 열린다. 원본 스냅샷은 유지되므로 복구 내용을 별도 저장하고 필요 없는 사본은 명시적으로 버린다. 다른 실행 창의 현재 사본일 수도 있다.
- 다른 프로그램/창이 원본을 바꾸거나 삭제하면 현재 창의 정상 저장은 거부한다. **다른 이름으로 저장**해 로컬 편집을 보존한 뒤 비교/병합한다. 자동 병합은 제공하지 않는다.
- 프로젝트 옆 `.uml-lock`은 저장 중 잠깐 존재한다. 강제 종료 후 남았다면 모든 관련 편집기를 종료하고 프로젝트와 복구를 백업한 뒤 그 잠금 파일만 제거한다. 실행 중인 writer의 잠금은 지우지 않는다.
- 로그 파일을 상시 기록하는 기능은 없다. UI의 오류 내용을 확인하고 터미널 실행 시 stderr를 수집한다. 프로젝트 내용/파일 경로가 포함될 수 있으므로 공유 전 검토한다.

## 내보내기

내보내기에서 PNG/SVG, 1x/2x/3x, 여백, 투명/흰 배경을 고른다. 전체 다이어그램을 내보내며 그리드·선택·UI는 제외한다. 한글 폰트는 포함되고 SVG 텍스트는 path로 변환된다. 최대 한 변 16,384px/4천만 픽셀 제한이 있다.

```sh
cargo run -- --export examples/review.umlproj /tmp/uml-png
cargo run -- --export-svg examples/review.umlproj /tmp/uml-svg
```

클라우드/로그인/동기화는 제공하지 않는다. 중요한 프로젝트는 별도 백업을 유지한다.
